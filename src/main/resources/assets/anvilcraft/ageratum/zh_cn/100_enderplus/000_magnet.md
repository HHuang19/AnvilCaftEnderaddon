# 功能

1. 手持魔棒 **右键** <ref item="minecraft:anvil"/>（或其变种），把它"吸"进魔棒里随身带走
2. 再 **右键** 一个位置，即可把携带的铁砧放置到方块上
3. 魔棒内部携带铁砧时，物品会带有附魔流光，悬浮提示会显示当前携带的铁砧
4. 一根魔棒同一时间只能携带一个铁砧
