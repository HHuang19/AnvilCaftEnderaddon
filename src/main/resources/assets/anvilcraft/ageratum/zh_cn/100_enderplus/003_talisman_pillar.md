# 挂载护符

末影护符柱是一个 **2 格高** 的多部分方块，用来展示与存储铁砧工艺的护符。

1. 手持带有护符数据组件的 **护符**，**右键** 柱子：把护符挂到玩家所在一侧
2. 每侧最多挂 **4 个**，四个侧面互不影响
3. **空手右键** 柱子：取下准星所指的护符
4. 拆除柱子时，上面挂着的护符会全部掉落

# 与末影护符联动

<ref item="anvilcraft_enderplus:ender_amulet"/> 可以绑定到护符柱上。绑定后，
柱子挂载的护符效果会"传递"给携带该护符的玩家。

# 其他

- 自发光亮度 15
- 放置时按玩家面对方向决定护符的悬挂侧
