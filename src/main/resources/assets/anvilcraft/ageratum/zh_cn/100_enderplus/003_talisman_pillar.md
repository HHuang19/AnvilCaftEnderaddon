# 挂载护符

末影护符柱是一个 **2 格高** 的方块，可用来展示与存储铁砧工艺的护符。

1. 手持 **护符**，**右键** 柱子：把护符挂到玩家面对的一侧
2. 每侧最多挂 **4 个**，四个侧面互不影响
3. **空手右键** 柱子：取下准星所指的护符
4. 拆除柱子时，上面挂着的护符会全部掉落
5. <ref item="anvilcraft_enderplus:ender_amulet"/> 可以绑定到护符柱上。绑定后，
柱子挂载的护符效果会传递给携带该护符的玩家。
