# 功能

末影输电杆是一个 **3 格高** 的多部分方块。它既是本地电网的 **输电元件**，也
能把两根互相绑定的杆所在的电网变成一个"共享电网"，从而实现 **跨维度输电**。

# 绑定与输电

1. 手持末影输电杆 **右键** 一根已放置的杆：未记录目标时，会记录该杆为绑定目标
2. 再 **右键** 另一根杆：把两根杆 **互绑** 成一条输电链路
3. 绑定后，两侧电网的发电 / 用电完全一致，等效于同一电网；任一侧过载，两侧同时过载
4. 潜行 + 右键空气：清除物品上记录的绑定目标
5. 潜行 + 空手右键已绑定的杆：解除该杆的绑定

# 红石控制

- 给杆的 **底部段** 输入红石信号会使输电杆 **断电**（切断输电）
- 无信号时恢复供电

<warning>
跨维度输电依赖两侧区块加载；远端区块未加载时无法输电，本附属的护符柱会自行强加载对应区块，但输电杆不会
</warning>

# 其他

- 通电时顶段满亮，过载时降低亮度
- 可通过铁砧工艺的锤子拆除
