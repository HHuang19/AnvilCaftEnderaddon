# 便携附属

## 欢迎查看《便携附属》附带的手册页面！

**便携附属**（Anvilcraft Portable Addon）是以
<ref item="anvilcraft:magnet_block"/> 与铁砧工艺电力系统为核心的附属模组。

* 新增 **磁铁魔棒**，可以随身携带并投放铁砧
* 新增 **能量方块** 与 **末影输电杆**，实现便捷发电与跨维度输电
* 新增 **末影护符柱** 与 **末影护符**，把护符效果装进口袋、跨维度随身携带
* 新增 **雷跃 / 雷行** 两种附魔，提供更强的机动能力
