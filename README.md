# AnvilCraft: Ender+

一个为《铁砧工艺》(AnvilCraft) 增加全新末影主题内容与机动能力的附属模组。

## 内容

* **磁铁魔棒**：随身携带并投放铁砧
* **能量方块** 与 **末影输电杆**：便捷发电与跨维度输电
* **末影护符柱** 与 **末影护符**：把护符效果装进口袋、跨维度随身携带
* **雷跃 / 雷行** 附魔：提供二段跳与闪现等更强的机动能力

## 构建

```bash
./gradlew.bat build
```

运行客户端：

```bash
./gradlew.bat runClient
```

## 依赖

* [AnvilCraft](https://github.com/AnvilCraft)（必需）
* [Curios API](https://github.com/TheIllusiveC4/Curios)（可选）
